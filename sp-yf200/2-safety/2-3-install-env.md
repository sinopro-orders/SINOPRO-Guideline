# 2-3. 설치 환경 주의사항

* 장비는 **평탄하고 견고한 바닥**에 설치하고, 수평을 확인하세요.
* 방열과 정비 공간 확보를 위해 장비 주변에 충분한 유격 거리를 두세요.
* 환기가 잘 되는 장소에 설치하세요. 글러브박스 내 설치 시에는 [3-2. 유틸리티 연결](../3-install/3-2-utility.md)의 KF40 밀봉 지침을 따르세요.
* **비상 정지 버튼**은 제어 패널에 있습니다. 설치 후 작업자가 즉시 조작할 수 있는 위치인지 확인하세요.

{% hint style="info" %}
**작성 필요** — 권장 유격 거리(mm), 바닥 평탄도 기준, 환기 요구 조건 등 구체 수치를 채워 주세요.
{% endhint %}
