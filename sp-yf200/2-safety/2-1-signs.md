# 2-1. 경고 표지 및 기호 설명

본 매뉴얼과 장비 표면에는 다음과 같은 안전 기호가 사용됩니다.

{% hint style="danger" %}
**위험 (DANGER)** — 지시를 따르지 않을 경우 사망 또는 중상으로 이어질 수 있는 임박한 위험 상황을 나타냅니다.
{% endhint %}

{% hint style="warning" %}
**경고 (WARNING)** — 지시를 따르지 않을 경우 사망 또는 중상으로 이어질 수 있는 잠재적 위험 상황을 나타냅니다.
{% endhint %}

{% hint style="info" %}
**주의 (CAUTION)** — 지시를 따르지 않을 경우 경상 또는 장비 손상으로 이어질 수 있는 상황을 나타냅니다.
{% endhint %}

## 장비 부착 경고 라벨

{% hint style="info" %}
**작성 필요** — 장비에 부착된 경고 라벨(고온 주의, 감전 주의, 끼임 주의 등)의 사진과 부착 위치를 정리해 주세요.
{% endhint %}

| 라벨 | 의미 | 부착 위치 |
| --- | --- | --- |
| 고온 주의 | 실링 헤드는 최대 250℃까지 가열됨 | 실링 유닛 부근 |
| 끼임 주의 | 커버·실린더 작동부에 손 접근 금지 | 챔버 커버 부근 |
| 감전 주의 | 통전 중 제어박스 개방 금지 | 제어박스 |
