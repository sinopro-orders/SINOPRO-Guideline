# 5-1. 정기 점검 항목

## 일간 점검

| 항목 | 내용 | 확인 |
| --- | --- | --- |
| 챔버 청소 | 상하 플레이트와 진공 챔버를 닦아 청결 유지 | ☐ |
| O링 상태 | 실링 고무링 장착 및 손상 여부 확인 | ☐ |
| 공압 압력 | 0.5~0.7MPa 범위 확인 | ☐ |

## 월간 점검

| 항목 | 내용 | 확인 |
| --- | --- | --- |
| 급유 | 베어링과 운동 부위에 오일 주입 | ☐ |
| 체결 상태 | 볼트·너트·핀 등의 고정 상태 점검, 풀림 방지 | ☐ |

## 연간 / 장기 미사용 시

| 항목 | 내용 | 확인 |
| --- | --- | --- |
| 방청 처리 | 장기간 미사용 시 동작 부위를 깨끗이 닦고 표면에 방청유 도포 | ☐ |
| 전기 안전 점검 | 절연·접지 상태 확인 | ☐ |
