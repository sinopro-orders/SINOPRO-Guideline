# 3-1. 운반 및 이동

1. 목재 포장을 제거한 후 장비를 조심스럽게 지정된 위치에 설치합니다.
2. 장비 무게는 약 50kg입니다. 운반 시 2인 이상 또는 운반 장비를 사용하세요.
3. 본체(작업부)와 제어박스는 분리형이므로 각각 운반합니다.

{% hint style="info" %}
**작성 필요** — 이동용 휠/고정 레벨러가 있는 경우 조작 방법(잠금/해제, 수평 조정)을 사진과 함께 추가해 주세요.
{% endhint %}
