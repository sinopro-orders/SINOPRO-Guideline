# 1-2. 장치 구성

## 외관

![SP-YF200 외관](../images/image3.png)

{% hint style="info" %}
**작성 필요** — 외관 사진에 번호를 표기하고 각 부위 명칭(진공 챔버, 상부 커버, 투시창, 시작 버튼, 제어박스 등)을 아래 표에 채워 주세요.
{% endhint %}

| 번호 | 명칭 | 기능 |
| --- | --- | --- |
| ① | 진공 챔버 | 제품 진공 밀봉 공간 |
| ② | 상부 커버(투시창 포함) | 챔버 개폐, 내부 관찰 |
| ③ | 시작 버튼(좌/우) | 양손 동시 조작으로 작업 시작 |
| ④ | 제어박스 | 온도·시간·압력 등 파라미터 제어 |
| ⑤ | (작성 필요) | (작성 필요) |

## 제어 패널 구성

![제어 패널](../images/image7.png)

| 스위치 | 기능 |
| --- | --- |
| 상부 가열 | 상부 실링 나이프의 가열 온/오프 전환 |
| 하부 가열 | 하부 실링 나이프의 가열 온/오프 전환 |
| 비상 정지 | 모든 동작 정지 |
| 커버 개폐 | 상부 커버 열림 및 닫힘 전환 |
| 진공 | 진공 밸브 온/오프 전환 (실링 작업 시 열림 상태) |
| 가스 주입 | 가스 주입 밸브 온/오프 전환 (실링 작업 시 닫힘 상태) |
| 실링 | 상하 실링 나이프 온/오프 전환 |
| 수동/자동 | 수동 및 자동 모드 전환 (작업 시 자동 모드 사용) |
