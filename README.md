## 장비 개요

**SP-YF200 Vacuum Pre-sealing Machine**은 소형 및 중형 소프트 패키지 리튬이온 전지를 전해액 주입 후 정치 공정까지 완료한 다음, 진공 상태에서 열프레스로 예비 밀봉하기 위한 장비입니다.
